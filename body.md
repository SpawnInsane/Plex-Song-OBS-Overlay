# Release notes

- Added Linux support with an applications-menu launcher and browser-based controls, plus Debian/Ubuntu installers for x86-64 and ARM64 and an Arch/AUR build recipe.
- Added signed APT repository publishing support for package-manager updates, source downloads, and instructions for building and installing locally from GitHub.
- Linux keeps the overlay running when the browser tab closes; stop it from the control page or with Ctrl+C when started in a terminal.
